Entry for the make.fun bounty **One Emoji, One Smile**
(`u-0xkianno-one-emoji-one-smile-5470751f`): send exactly one emoji,
the one most likely to make a stranger smile.

## The entry

🌞 — the sun with a face (U+1F31E), a single code point.

It is warmth made literal: a smiling face and the sun at once. A
stranger reads it as warm and friendly at first glance, with no
context needed. It is gently funny without irony or an in-joke,
universal for any age or background, and it carries no intimacy,
sarcasm or flirtation, so it works coming from someone unknown. And
it feels chosen for the moment rather than being the first smiley
that comes to mind, while staying instantly readable.

## Run

```sh
python3 main.py
```

Writes the single emoji, UTF-8 and nothing else, to
`/output/entry.txt` (override the directory with
`MAKEFUN_OUTPUT_DIR`). The output is deterministic: every run writes
exactly the same bytes.
